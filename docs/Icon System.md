# 🎨 Icon System

A lightweight, framework-agnostic icon system for React + Vite that reads SVG
files from `public/icon/` and exposes them through typed components and hooks.

---

## 📁 Overview

| Item | Location | Purpose |
|---|---|---|
| SVG assets | `public/icon/*.svg` | The actual icon files |
| Generator script | `scripts/generate-icons-manifest.mjs` | Builds `manifest.json` |
| Manifest | `public/icon/manifest.json` | Auto-generated index of all icons |
| Base component | `src/components/Icon/Icon.tsx` | `<Icon />` + `useIcons()` |
| Inline component | `src/components/Icon/InlineIcon.tsx` | `<InlineIcon />` for `currentColor` |
| Picker component | `src/components/Icon/IconPicker.tsx` | `<IconPicker />` dropdown with search |

---

## 🚀 Quick Start

```tsx
npm run icons

import { Icon } from '@/components/Icon/Icon';

<Icon name="deepseek" size={32} />

## 🧪 Usage Examples

```tsx
// Default variant
<Icon name="deepseek" size={32} />

// Pick a specific variant explicitly
<Icon name="anthropic-dark" size={32} />

// Or let the component resolve the variant for you
<Icon name="anthropic" variant="dark" size={32} />
// → tries "anthropic-dark.svg" first, then falls back to "anthropic.svg"

// Inline (inherits currentColor) — good for mono variants
<InlineIcon name="nvidia-mono" forceCurrentColor className="text-blue-600" />

// Pick from a dropdown
<IconPicker value={icon} onChange={setIcon} />
